# EE Import panel

**EE Import** is a docked VS Code Panel container, next to the terminal. It presents a compact live list of import operations rather than a full editor table.

Each row shows its state, description or operation ID, and elapsed time after it starts. Pending tasks omit start time and duration. Running or pending tasks can be cancelled; successful tasks with a recognised destination asset expose a preview action. Use **Open in Editor** for the [Import Tasks editor](../editors/import-tasks).
