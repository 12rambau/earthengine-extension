# EE Export panel

**EE Export** is a docked VS Code Panel container, next to the terminal. It presents a compact live list of export operations rather than a full editor table.

Each row shows its state, description or operation ID, and elapsed time after it starts. Pending tasks omit start time and duration. Running or pending tasks can be cancelled; successful tasks with a recognised destination asset expose a preview action. Use **Open in Editor** for the [Export Tasks editor](../editors/export-tasks).
