# Assets and previews

## Asset browser

The **Assets** sidebar reflects the hierarchy of the active Earth Engine project. Folders and ImageCollections expand lazily, so opening a large library does not block VS Code. The browser identifies folders, images, ImageCollections, and tables with distinct icons.

Use the title actions to search, refresh the root, open the Asset Manager, or create a folder. Right-click an item to refresh a container, preview supported assets, copy its ID, or perform copy, move, and delete operations.

## Asset Manager editor

**Open Asset Manager** opens a paginated full-page table for the current project. It supports breadcrumb navigation, folder drill-down, sortable columns, an inline preview action, and copy, move, delete, and create-folder operations.

Long-running recursive copy, move, and delete operations report the complete asset path currently being processed in the VS Code notification area.

## Image preview

An **Image** preview presents its thumbnail and core metadata in a sidebar. Its tabs contain:

- **Description** from the asset metadata.
- **Bands** with type, dimensions, CRS, nominal scale, and asynchronously calculated min/max values.
- **Properties** excluding system properties and the description field.

## ImageCollection preview

An **ImageCollection** preview creates a mosaic thumbnail from the first available images. Its tabs provide the collection description, a paged list of child images, bands from the first child image, and properties. The child-image table can open an image preview or delete that image.

## Table preview

A **Table** or FeatureCollection preview renders an outline thumbnail and exposes:

- **Description**.
- **Features**, limited to the first 20 rows.
- **Columns**, inferred from the first feature's properties.
- **Properties**, excluding system keys.
