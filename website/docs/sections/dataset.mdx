# Dataset section

The **Dataset** sidebar section browses the Earth Engine STAC catalog across Google, Publisher, and Community provider tiers. Dataset type resolution happens lazily to keep browsing responsive.

Search or refresh catalog entries from the view title. Context actions copy a dataset ID, open its source page, or open the [Dataset details editor](../editors/dataset-details).
