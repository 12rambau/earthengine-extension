# Import Tasks section

The **Import Tasks** sidebar section is the compact Activity Bar view for ingestion and import operations. Filter its contents, refresh task state, and cancel eligible running tasks from contextual actions.

For a docked monitoring surface use the [EE Import panel](../panels/ee-import); for sorting, pagination, and a detailed table open the [Import Tasks editor](../editors/import-tasks).
