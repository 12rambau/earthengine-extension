# Profiles

The **Profiles** sidebar section manages the credentials and Google Cloud project used by every Earth Engine request in the extension.

Use **Add Profile** for Google OAuth or **Add Service Account** for a service-account key file. Select a profile to make it active; the active state is marked in the tree. Context actions let you sign out, remove a profile, or create a Python script for the map bridge.

Credentials are stored under `~/.config/earthengine/profiles/`, matching the Earth Engine CLI location.
