# Export Tasks section

The **Export Tasks** sidebar section is the compact Activity Bar view for export operations. Filter its contents, refresh task state, and cancel eligible running tasks from contextual actions.

For a docked monitoring surface use the [EE Export panel](../panels/ee-export); for sorting, pagination, and a detailed table open the [Export Tasks editor](../editors/export-tasks).
