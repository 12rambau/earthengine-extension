# API Docs section

The **Docs** sidebar section contains the searchable Earth Engine JavaScript API registry. Browse namespaces such as `ee.Image`, `ee.FeatureCollection`, and `ee.Reducer`, then inspect tooltips for descriptions, arguments, and return types.

Use **Search API Docs** to locate symbols and **Refresh API Docs** to retrieve the registry again for the active profile.
