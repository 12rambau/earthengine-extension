# Interactive Map editor

The **Interactive Map** is a singleton Leaflet Webview editor. Open it from the Profiles view title action or **Open Map View**. It follows the VS Code light or dark theme by default and can switch to satellite or plan basemaps.

Manage layer visibility and opacity, open the visualization editor for RGB, HSV, continuous, categorical, or interval rendering, and expose a scale. The inspector samples visible layers at a clicked point, while the status bar reports coordinates and zoom.

The local Python bridge listens on `localhost:31415` for scripts that add Earth Engine tile layers or update the viewport.

## Preset visualization parameters

Images added to the map can carry one or more preset visualizations as asset properties, following the same convention used by SEPAL. When present, these presets appear in the visualization editor's **Preset…** dropdown so a collaborator can reuse the exact rendering a dataset was designed with, instead of guessing bands, ranges, and palettes from scratch.

The examples on this page describe `projects/earthengine-extension/assets/demo-image`. It is a multi-source composite clipped to metropolitan France using FAO GAUL 2024 L0 (`gaul0_name = France`). Its grid is EPSG:4326 at approximately 100 m nominal resolution. Each band retains its own mask; coarser source products are resampled to this grid without gaining spatial detail.

### Create a visualization

To create an `ee.Image` compatible with the visualization tool, add extra properties to the image using the `set` method:

```python
import ee

image = ee.Image('projects/earthengine-extension/assets/demo-image')

image_with_preset = image.set({
  "visualization_0_name": "Sentinel-2 RGB - July 2026",
  "visualization_0_bands": "s2_red,s2_green,s2_blue",
    "visualization_0_type": "rgb",
    "visualization_0_min": "0",
  "visualization_0_max": "3000"
})
```

To create a visualization parameter, properties are added as a JSON dictionary to the image.

:::note
You can set as many visualizations in the dictionary as you want. Each one will be differentiated by its ID number and interpreted separately.
:::

Each property key starts with `visualization_<number>_<keyword>`. The number identifies a preset; the keyword identifies a property such as `name`, `type`, `bands`, `min`, or `max`. Property values are strings, with comma-separated values for lists such as `bands`, `palette`, `breaks`, `labels`, and `values`.

### Bands and sources

| Band(s) | Source and interpretation |
| --- | --- |
| `s2_red`, `s2_green`, `s2_blue` | Harmonized Sentinel-2 surface reflectance B4/B3/B2: July 2026 median, with clear pixels selected using Cloud Score+ (`cs_cdf >= 0.60`). Values retain the source product's encoded reflectance scale. |
| `viirs_ndvi` | NASA VIIRS VNP13A1.002: median NDVI from composites dated July 2026, in the source product's units. |
| `era5_tmax_c` | Hourly ERA5-Land: maximum 2 m air temperature across July 2026, converted from kelvin to degrees Celsius. |
| `era5_tmax_class` | Class index 0 to 22 for `era5_tmax_c`, using Celsius lower bounds -45, -40, -35, -30, -25, -20, -17.5, -15, -10, -5, -2.5, 0, 5, 10, 15, 20, 25, 30, 32.5, 35, 37.5, 40, and 45. |
| `corine_landcover` | Copernicus CORINE V20 100 m, 2018 inventory: original land-cover class codes (111 to 523). |
| `corine_class_index` | Index 0 to 43 of CORINE classes in ascending class-code order; used with the official display palette. Use `corine_landcover` for original codes. |
| `dem_elevation` | Copernicus DEM GLO-30 2024_1: digital surface model elevation in metres (EGM2008 vertical datum). |
| `terrain_slope`, `terrain_aspect`, `terrain_hillshade` | Derived from the DEM: slope in degrees, aspect in degrees (0 to 360), and hillshade from 0 to 255. |
| `hsv_hue`, `hsv_saturation`, `hsv_value` | Terrain HSV components: aspect / 360, slope / 35 capped at 1, and hillshade / 255 * 0.75 + 0.25. Each component ranges from 0 to 1. |
| `terrain_red`, `terrain_green`, `terrain_blue` | RGB conversion of the terrain HSV image, with components ranging from 0 to 1. |

CORINE covers Europe, so pixels outside its coverage remain masked. Display palettes are visualization settings, not stored band values. The terrain RGB bands are derived data bands; the preset below uses the separate HSV component bands directly.

The source datasets are [FAO GAUL 2024 L0](https://gee-community-catalog.org/projects/gaul/) (`projects/sat-io/open-datasets/FAO/GAUL/GAUL_2024_L0`), [Harmonized Sentinel-2 surface reflectance](https://developers.google.com/earth-engine/datasets/catalog/COPERNICUS_S2_SR_HARMONIZED) (`COPERNICUS/S2_SR_HARMONIZED`), [Cloud Score+ S2_HARMONIZED V1](https://developers.google.com/earth-engine/datasets/catalog/GOOGLE_CLOUD_SCORE_PLUS_V1_S2_HARMONIZED) (`GOOGLE/CLOUD_SCORE_PLUS/V1/S2_HARMONIZED`), [VIIRS VNP13A1.002](https://developers.google.com/earth-engine/datasets/catalog/NASA_VIIRS_002_VNP13A1) (`NASA/VIIRS/002/VNP13A1`), [ERA5-Land hourly](https://developers.google.com/earth-engine/datasets/catalog/ECMWF_ERA5_LAND_HOURLY) (`ECMWF/ERA5_LAND/HOURLY`), [Copernicus CORINE Land Cover V20 100 m](https://developers.google.com/earth-engine/datasets/catalog/COPERNICUS_CORINE_V20_100m) (`COPERNICUS/CORINE/V20/100m`, 2018), and [Copernicus DEM GLO-30 2024_1](https://developers.google.com/earth-engine/datasets/catalog/COPERNICUS_DEM_GLO30_2024_1) (`COPERNICUS/DEM/GLO30_2024_1`).

### Presets stored on the demo image

The `demo` command adds one layer for each of these five presets. `name`, `type`, and `bands` identify the rendering; numeric bounds and comma-separated lists are also stored as strings on the asset.

#### Sentinel-2 RGB (July 2026)

True-color rendering from the July 2026 Sentinel-2 median. Cloudy pixels are masked using Cloud Score+ `cs_cdf >= 0.60`.

```json
{
  "visualization_0_name": "Sentinel-2 RGB - July 2026",
  "visualization_0_type": "rgb",
  "visualization_0_bands": "s2_red,s2_green,s2_blue",
  "visualization_0_min": "0",
  "visualization_0_max": "3000"
}
```

#### VIIRS NDVI (July 2026)

Continuous rendering of the VIIRS NDVI band. Lower NDVI values are brown and higher values are green.

```json
{
  "visualization_1_name": "VIIRS NDVI - July 2026",
  "visualization_1_type": "continuous",
  "visualization_1_bands": "viirs_ndvi",
  "visualization_1_min": "0.0199",
  "visualization_1_max": "1.093",
  "visualization_1_palette": "#8c5a3c,#e2c76a,#d9e9aa,#75b878,#126c46"
}
```

#### ERA5-Land maximum temperature (July 2026)

Interval rendering of maximum 2 m air temperature in degrees Celsius. The 24 increasing boundaries define 23 intervals; the 23 colors map to those intervals in order. Values outside the outer bounds (-273.15 and 100 °C) are transparent. The separate `era5_tmax_class` band contains class indices 0 to 22.

```json
{
  "visualization_2_name": "ERA5-Land maximum 2m temperature - July 2026",
  "visualization_2_type": "intervals",
  "visualization_2_bands": "era5_tmax_c",
  "visualization_2_breaks": "-273.15,-40,-35,-30,-25,-20,-17.5,-15,-10,-5,-2.5,0,5,10,15,20,25,30,32.5,35,37.5,40,45,100",
  "visualization_2_palette": "#BA68C8,#8E24AA,#6A1B9A,#7E57C2,#B39DDB,#ccd0ed,#1A237E,#0D47A1,#1565C0,#03A9F4,#00ffff,#1B5E20,#43A047,#8BC34A,#FFF176,#FFCA28,#FFA000,#FF6F00,#cd2000,#96132d,#fab2f5,#F06292,#E91E63"
}
```

`breaks` is an extension preset property, not a standard Earth Engine `Map.addLayer` visualization parameter.

#### Copernicus DEM terrain HSV

The terrain preset displays `hsv_hue`, `hsv_saturation`, and `hsv_value`, each ranging from 0 to 1. Hue follows aspect, saturation follows slope, and value follows hillshade.

```json
{
  "visualization_4_name": "Copernicus DEM terrain HSV",
  "visualization_4_type": "hsv",
  "visualization_4_bands": "hsv_hue,hsv_saturation,hsv_value",
  "visualization_4_min": "0,0,0",
  "visualization_4_max": "1,1,1"
}
```
