# Table preview editor

A **Table preview** opens from a FeatureCollection asset. It renders an outline thumbnail and displays its ID, dates, size, feature count, and last-modified time.

The **Features** tab shows the first 20 rows. **Columns** infers property types from the first feature. **Description** and **Properties** display asset metadata while excluding system keys.
