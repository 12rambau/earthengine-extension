# Customizing map basemaps

The map has separate basemap settings for the default and plan views in both VS Code
colour themes. This example uses GitHub-inspired light and dark dimmed colours. Add the
following to your VS Code `settings.json` to replace all four slots:

:::danger[Google Maps API key required]

These custom styles only work when the map uses Google Map Tiles. Set up a Google Maps
API key with the Map Tiles API enabled as described in
[the API key setup guide](../settings#setting-up-the-api-key). Without a valid key, the
map uses OpenStreetMap and Esri fallback tiles, which do not support these styles.

:::

The `light` and `dark` settings control the default basemap. The `planLight` and
`planDark` settings control the basemap shown when the plan toggle is active. The
satellite toggle is unchanged by this example. For details on each setting and other
customization options, see the [settings reference](../settings#basemap-slots).

VS Code applies changes to an open map immediately.
