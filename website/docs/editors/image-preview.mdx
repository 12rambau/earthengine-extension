# Image preview editor

An **Image preview** opens from an Image asset. Its sidebar holds the thumbnail, asset ID, dates, size, band count, and last-modified time.

The **Description** tab renders the asset description. **Bands** shows each band's type, dimensions, CRS, nominal scale, and asynchronously computed min/max values. **Properties** excludes system fields and the description.
