# ImageCollection preview editor

An **ImageCollection preview** opens from an ImageCollection asset and creates a mosaic thumbnail from its first available images.

Its tabs expose the collection description, child images, bands from the first child image, and properties. The **Images** tab can open an individual image preview or delete a child image.
