# Export Tasks editor

The **Export Tasks** Webview editor is the detailed table surface for export operations. Open it from the Export Tasks sidebar section, the [EE Export panel](../panels/ee-export), or the Command Palette.

It streams pages as they load, supports sortable columns and pagination, then silently refreshes non-terminal operations every 15 seconds. Rows include cancellation, destination information where available, and preview actions for resulting assets.
