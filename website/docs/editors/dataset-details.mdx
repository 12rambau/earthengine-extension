# Dataset details editor

The **Dataset details** Webview editor opens from a catalog item. It provides a preview image when available, temporal coverage, provider metadata, tags, a copyable Earth Engine snippet, and a link to the catalog source.

The available tabs are **Description**, **Bands**, and, for Community entries, **Properties**.
