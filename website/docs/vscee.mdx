# vscee Python library

**vscee** is the Python package that bridges scripts to the extension's
[Interactive Map](./editors/interactive-map) editor. It ships from the `python/` folder
of this repository and is published to PyPI so it can be installed independently of the
extension.

Earth Engine graphs are built and serialised entirely on the Python side with the
official `earthengine-api`; `vscee` only forwards the serialised object and display
parameters to the extension over a local HTTP bridge. The extension host resolves tile
URLs with the EE JS client — the Python side never calls `getMapId` or resolves tiles
itself.

## How it works

`vscee` never talks to Earth Engine servers on the extension's behalf. Each `Map.*` call
sends a JSON POST request to a local HTTP server the extension starts on
`127.0.0.1:31415`, exposing one endpoint per function (`addLayer`, `centerObject`,
`setCenter`, `clear`). The extension listens for these requests and forwards them to the
Leaflet Webview to update the map. If the extension is not running or the map panel has
not started the bridge server, calls fail silently and print a warning instead of
raising.

## Install

```bash
pip install vscee
```

To install the version tracked by this repository instead of the PyPI release:

```bash
pip install -e python/
```

## Requirements

- Python `>=3.9`
- The Earth Engine extension installed and active in VS Code
- A valid `ee.Initialize(project=...)` call before any `Map.*` invocation

Select **New Python Script** from the Profiles view title action, or the
`earthengine.newScript` command, to generate a script prefilled with the initialisation
boilerplate and `Map` import shown below.

## The `Map` module

`vscee` exposes a single `Map` module that mirrors the `Map` global of the Earth Engine
Code Editor. There is only one map panel in the extension, so `Map` is a module of
functions rather than a class you instantiate:

```python
import ee
from vscee import Map

ee.Initialize(project="my-project")

image = ee.Image("COPERNICUS/S2_SR_HARMONIZED/20200101T100319_20200101T100321_T32TQM")
Map.addLayer(image, {"bands": ["B4", "B3", "B2"], "min": 0, "max": 3000}, "RGB")
Map.centerObject(image, zoom=10)
```

:::warning

`vscee` intentionally supports more visualization parameters than the original Earth
Engine Code Editor. RGB and continuous parameters can be used as-is in both. HSV and
interval parameters are supported only by `vscee` and tools that have adopted this
convention; they are not supported by the original Code Editor.

:::

### Map.addLayer

#### Prototype

```python
Map.addLayer(ee_object, vis_params=None, name=None, shown=True, opacity=1.0)
```

Add a layer to the map. `ee_object` accepts one of these two groups:

- **Image:** an `ee.Image` or `ee.ImageCollection` (mosaicked automatically). Supports
  RGB, HSV, continuous, categorical, and interval rendering.
- **FeatureCollection:** an `ee.FeatureCollection`, `ee.Feature`, or `ee.Geometry`;
  features and geometries are converted to a FeatureCollection automatically. Supports
  uniform styling and property-based continuous, categorical, and interval rendering.

The `type` parameter is optional for direct calls: `breaks` select intervals, `values`
select categorical, and a palette without either selects continuous. Otherwise images
use RGB and feature collections use uniform styling. Set `type` explicitly for HSV,
which cannot be distinguished from RGB by its bands. An empty dictionary selects the
first stored preset for an image when available; `default` selects a stored preset for
either source. Stored `visualization_<number>_type` properties still require a type.

The [map's visualization editor](./editors/interactive-map#visualization-parameters)
exposes the same modes and parameters.

:::danger

- `type` is optional for direct calls, but strongly recommended to make the intended
    rendering mode explicit.
- `labels` is optional for both categorical `values`/`palette` and interval
    `breaks`/`palette`.
- HSV cannot be inferred from its three bands: set `"type": "hsv"` explicitly.

:::

#### Image

##### RGB

To display an image with an RGB color scheme, assign one image band to each display
channel in red-green-blue order. Set `min` and `max` to define the input range stretched
across each channel's 0–255 display range. A single number applies to all three bands;
pass three values to set a separate range for each band. `gamma` is optional and adjusts
midtone brightness.

This example displays Sentinel-2 B4, B3, and B2 as red, green, and blue:

```python
image = ee.Image("projects/earthengine-extension/assets/demo-image")
Map.addLayer(
    image,
    {
        "type": "rgb",
        "bands": ["s2_red", "s2_green", "s2_blue"],
        "min": 0,
        "max": 3000
    },
    "Sentinel-2 RGB - July 2026",
)
Map.centerObject(image, zoom=6)
```

##### HSV

HSV rendering interprets three bands as hue, saturation, and value. Set `type` to
`"hsv"`, provide three `bands`, and set the corresponding `min` and `max` ranges. Each
band is normalized to 0–1 before the image is converted to RGB for display.

```python
image = ee.Image("projects/earthengine-extension/assets/demo-image")
Map.addLayer(
    image,
    {
        "type": "hsv",
        "bands": ["hsv_hue", "hsv_saturation", "hsv_value"],
        "min": [0, 0, 0],
        "max": [1, 1, 1],
    },
    "Copernicus DEM terrain HSV",
)
Map.centerObject(image, zoom=6)
```

##### Continuous

Continuous rendering maps values in one band through a color palette. Provide the band,
a `min` and `max` stretch range, and at least two palette colors. A palette without
`values` or `breaks` is interpreted as continuous, with no `type` required.

```python
image = ee.Image("projects/earthengine-extension/assets/demo-image")
Map.addLayer(
    image,
    {
        "type": "continuous",
        "bands": ["viirs_ndvi"],
        "min": 0.0199,
        "max": 1.093,
        "palette": ["#8c5a3c", "#e2c76a", "#d9e9aa", "#75b878", "#126c46"],
    },
    "VIIRS NDVI - July 2026",
)
Map.centerObject(image, zoom=6)
```

##### Intervals

Interval rendering assigns a palette color to each range in one band. `breaks` must be
strictly increasing and have exactly one more value than the number of colors. Each
interval includes its lower bound and excludes its upper bound; optional `labels` appear
in the map scale.

image = ee.Image("projects/earthengine-extension/assets/demo-image")
Map.addLayer(
    image,
    {
        "bands": ["era5_tmax_c"],

#### FeatureCollection

For feature collections, `bands` is replaced by a feature `property`. Uniform styling
does not require a property; property-based modes use one selected property. Palette
colors must be six-digit hex RGB, with or without a leading `#`.

##### Uniform

Use `color` for outlines, `fillColor` for polygon fills, `width` for line width, and
`pointSize` for points. Fill is transparent by default.

```python
features = ee.FeatureCollection("projects/earthengine-extension/assets/demo-collection")
Map.addLayer(
    features,
    {
        "type": "uniform",
        "color": "#008000",
        "fillColor": "#FFFFFF",
        "width": 2},
    "Demo collection - uniform",
)
Map.centerObject(features, zoom=6)
```

### Map.centerObject

#### Prototype

```python
Map.centerObject(ee_object, zoom=None)
```

Centers and, optionally, zooms the map on the bounds of an `ee.Image`,
`ee.ImageCollection`, `ee.FeatureCollection`, `ee.Feature`, or `ee.Geometry`. Computing
the bounds calls `getInfo()`, so it requires network access to Earth Engine.

### Map.setCenter

#### Prototype

```python
Map.setCenter(lon, lat, zoom=None)
```

Sets the map viewport to explicit coordinates without querying Earth Engine.

### Map.clear

#### Prototype

```python
Map.clear()
```

Removes every layer currently on the map.
