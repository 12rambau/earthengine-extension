# Interactive map

**Open Map View** creates a singleton Leaflet editor panel for Earth Engine tile layers. It follows the VS Code light or dark theme by default and can switch to satellite or plan basemaps.

## Working with layers

Use the layer control to toggle visibility, adjust opacity, open the visualisation editor, and show a scale. The visualisation editor supports RGB, HSV, continuous palettes, and categorical classes. It can compute min/max values for the selected layer to fill empty range fields.

The pixel inspector samples visible layers at a clicked map location. The map status bar reports cursor coordinates and zoom.

## Python bridge

The local bridge listens on `localhost:31415` so Python scripts can add Earth Engine map tiles and set the viewport. Add the extension's `python/` directory to your module path before importing `Map`.

```python
import sys

sys.path.insert(0, "/path/to/extension/python")
from earthengine_vscode_map import Map

vis = {"min": 0, "max": 3000, "bands": ["B4", "B3", "B2"]}
Map.addLayer(ee_image.getMapId(vis)["tile_fetcher"].url_format, vis, "Landsat")
Map.centerObject(geometry, zoom=8)
```

The default basemaps can be changed in VS Code settings. See [Settings](./settings) for all supported providers and options.
