# Settings reference

Configure the extension through VS Code Settings using the `earthengine.*` keys below.

## Tasks

| Setting | Default | Range | Description |
| --- | --- | --- | --- |
| `earthengine.tasks.maxItems` | `100` | `10`–`1000` | Maximum tasks displayed by sidebar and panel tree views. |
| `earthengine.tasks.scanLimit` | `1000` | `100`–`5000` | Maximum operations fetched while loading or refreshing tasks. |
| `earthengine.tasks.historyDays` | `30` | `1` or more | Number of days of task history to load. |

## Map basemaps

Each of the four basemap slots (`earthengine.map.darkBasemap`, `lightBasemap`, `satelliteBasemap`, `planBasemap`) is an object with the same shape:

| Field | Type | Description |
| --- | --- | --- |
| `name` | `string` | Display name shown in the map's layer picker. |
| `provider` | `string` | A [leaflet-providers](https://github.com/leaflet-extras/leaflet-providers) ID. Ignored when `override` is enabled. |
| `override` | `boolean` | When `true`, ignore `provider` and load `url`/`attribution` instead. |
| `url` | `string` | Custom XYZ tile URL template, e.g. `https://tile.example.com/{z}/{x}/{y}.png`. Used only when `override` is enabled. |
| `attribution` | `string` | Custom attribution HTML shown on the map. Used only when `override` is enabled. |

| Setting | Default provider | Used when |
| --- | --- | --- |
| `earthengine.map.darkBasemap` | `CartoDB.DarkMatter` | VS Code uses a dark colour theme. |
| `earthengine.map.lightBasemap` | `CartoDB.Positron` | VS Code uses a light colour theme. |
| `earthengine.map.satelliteBasemap` | `Esri.WorldImagery` | Satellite/imagery view is active. |
| `earthengine.map.planBasemap` | `CartoDB.Voyager` | Plan view is active. |

:::warning[Provider API keys]

Some providers, including Jawg and Thunderforest, require an API key. Run **Earth Engine: Set Basemap API Key** from the Command Palette to store a key for a given slot — keys are kept in VS Code's secret storage, not in `settings.json`. Reopen the map after changing a key for it to take effect.

For a provider not covered by `provider`'s list, or full control over the tile source, enable `override` on that basemap and set `url`/`attribution` directly.

:::
